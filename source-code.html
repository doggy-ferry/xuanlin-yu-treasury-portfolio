Source Code

VBA modules and Power Query scripts for the cash-flow automation demo

Sanitised source samples use synthetic data, generic fields and <ROOT_PATH> placeholders. The author defined the business rules, controls and acceptance tests; AI-assisted coding supported implementation and documentation.

VBA modules (.bas)

FileResponsibility
modCommon.basConfiguration read, workbook lookup, latest file, timestamps, header location. CLEAR_LEFTOVER defaults to False.
modARImport.basAR source checks, company-code check, header comparison, value import, formula extension
modAPImport.basQuery refresh, row and header checks, value import, formula extension, pivot refresh
modBankImport.basQuery refresh, first/last header checks, value import, formula extension, timestamp, pivot refresh

Power Query scripts (.pq)

FileResponsibility
Query_AP.pqLatest AP Payment Detail text file, type normalisation, Source File column
Query_BANK.pqCombines bank files, extracts the account key as text, keeps the source file name
Query_AR.pqLatest AR Balance Report, restores sparse XML cells, cleans dates and amounts

README.txt lists the implemented controls and the boundaries of the code.

Use: import the .bas modules into a reviewed .xlsm copy; paste the .pq scripts into the Power Query Advanced Editor and adapt <ROOT_PATH> and the generic fields to your schema.
